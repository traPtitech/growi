# traQスタンプ

GROWIのMarkdown描画処理で、旧Crowiのスタンプ記法を使用できる。traQのMarkdownレンダラー全体は置き換えない。

| 記法 | 表示 |
| --- | --- |
| `:stamp:` | traQスタンプ、32px |
| `:stamp;` | traQスタンプ、24px |
| `:@username:` | traQユーザーアイコン、32px |
| `:@username;` | traQユーザーアイコン、24px |

閲覧・プレビュー・履歴・コメントで同じように表示され、見出し、表、リンクラベルでも使用できる。コード、数式、画像のalt属性、HTML属性内の記法は変換しない。バックスラッシュでエスケープした記法と、未知のスタンプ名は文字として残す。

traQの一覧にあるスタンプ名は、同名のGROWI標準絵文字より優先する。`.large`・`.rotate`などのエフェクトや、スタンプの入力補完・ピッカーには対応しない。本文や履歴は書き換えない。

## 設定

`TRAQ_ENABLED=true`の場合は標準で有効になる。認証とは別に有効・無効を切り替える場合は、`TRAQ_STAMPS_ENABLED`に`true`または`false`を設定する。

接続先には`TRAQ_ISSUER_HOST`のオリジンを使用し、未指定の場合は`https://q.trap.jp`を使用する。設定変更後はGROWIを再起動する。

公開APIの`/api/1.0/public/emoji.json`と`/api/1.0/public/emoji.css`、`/api/v3/public/icon/{username}`を利用する。認証情報やtraQのユーザー一覧を取得する必要はない。

スタンプ一覧はサーバープロセス内で5分間キャッシュし、同じ一覧をSSRとブラウザーへ渡す。取得のタイムアウトは3秒。

更新に失敗した場合は直前の一覧を保持し、失敗から1分以上経過した後のリクエストで再取得する。初回取得に失敗した場合、通常スタンプは既存の絵文字処理で表示するか、文字列のまま残す。ユーザーアイコンは一覧がなくても表示対象になる。

公開CSSと画像はブラウザーがtraQから取得するため、ネットワークやtraQ側の公開APIが利用できない場合は画像を表示できない。カスタムのサニタイズ設定を使う場合は、`i`タグと`class`・`title`・`style`属性を許可する必要がある。
